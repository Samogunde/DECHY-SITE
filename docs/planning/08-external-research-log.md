# External Research Log

Purpose: current external technical research that informs architecture decisions. This is **not** company information and never becomes a DECHY fact. Findings come from web search results on 2026-10-04 and must be re-verified at scaffold time because versions and advisories change.

| # | Topic | Finding | Implication for DECHY | Source |
|---|---|---|---|---|
| R1 | Next.js versions | Next.js 16 is the current line (released 2025-10-22). The newest listed release is 16.3.8 (2026-09-30), Active LTS; the 15.x line is at 15.5.27. A dedicated Next.js "May 2026 security release" exists. The 16.3.8 release addresses one high, five medium, and one low severity vulnerabilities. | Scaffold on the newest patched 16.x release, pin it, and enable Dependabot. Read the security advisories at scaffold time. | [endoflife.date Next.js](https://endoflife.date/nextjs), [Vercel May 2026 security release](https://vercel.com/changelog/next-js-may-2026-security-release), [Next.js releases](https://releasebot.io/updates/vercel/next-js) |
| R2 | React Server Components RCE | CVE-2025-55182 (React) and CVE-2025-66478 (Next.js): critical remote code execution in React Server Components in React 19.0 to 19.2.0 and Next.js 15 and 16 lines. Patched in React 19.0.1, 19.1.2, 19.2.1 and Next.js 15.0.5 to 15.5.7 and 16.0.7. | Never install below the patched versions. Prefer static output with a minimal server surface. Add a CI check that fails on known vulnerable versions. | [Vercel summary](https://vercel.com/changelog/cve-2025-55182), [Microsoft analysis](https://www.microsoft.com/en-us/security/blog/2025/12/15/defending-against-the-cve-2025-55182-react2shell-vulnerability-in-react-server-components/) |

Static-first design limits exposure to runtime or adapter changes. Re-check Netlify's docs when deploying. | [Netlify docs](https://docs.netlify.com/build/frameworks/framework-setup-guides/nextjs/overview/), [OpenNext on Netlify](https://opennext.js.org/netlify), [3 years of OpenNext](https://opennext.js.org/news/2026-03-25-3-years-of-opennext) |

| R5 | Google and AI features | Google's guidance states that no special files (including `llms.txt`), AI-specific markup, or content chunking are needed to appear in AI Overviews or AI Mode, and Google ignores such files. Do not promise AI citations. | [Google AI optimization guide](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide), [Contentful on llms.txt](https://www.contentful.com/blog/llms-txt-search-visibility/) |
